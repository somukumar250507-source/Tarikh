# Privacy

Tarikh stores workspace data and attachments in browser IndexedDB and local encrypted recovery files in OPFS. The hosted build is designed not to send case records, documents or backup passwords to GitHub. GitHub serves application assets and version checks and may process ordinary hosting access logs. Opening external meeting links is a separate action. Local records are not encrypted by Tarikh. Automatic backup key material is retained locally if enabled. Exported backups require a password; ordinary dossier PDFs are not encrypted. The host can publish executable updates, so use only a trusted deployment. Browser storage is origin-wide: other applications on the same origin may have access to it. Use a dedicated hosting origin for sensitive use. Beta testers should use dummy data only.
